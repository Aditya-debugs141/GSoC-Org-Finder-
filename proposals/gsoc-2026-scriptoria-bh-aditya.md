## 2. Project Title

**Scriptoria** — A Pre-Film Screenplay Management Website

---

## 3. Project Summary

Scriptoria is a web-based pre-film production management platform that helps filmmakers, writers, and production teams plan and manage every aspect of a screenplay before filming begins. It orchestrates multiple engines and an API key framework to deliver a unified workspace covering:

- **Screenplay planning** — structuring scenes, acts, and story arcs
- **Budget estimation** — overall cost breakdowns and per-scene budgets
- **Character management** — cast profiles and character arcs
- **Location management** — scouting notes and logistics
- **Visual references** — curated reference images and videos per scene
- **Audio/soundtrack planning** — background score and sound design references
- **Estimated cost rollups** — aggregated production cost reporting

---

## 4. Motivation

Film pre-production is one of the most fragmented phases in the industry. Writers, directors, and producers currently juggle spreadsheets, PDFs, sticky notes, and disconnected tools. Scriptoria brings all of these workflows into a single, structured, browser-based application — no install required, no vendor lock-in.

As someone deeply interested in web development and storytelling, I want to build a tool that genuinely serves creative teams, while sharpening my skills in modern JavaScript patterns, API integration, and UI/UX design.

## 5. Technical Approach

### Tech Stack
- **Frontend:** HTML, CSS, JavaScript (Vanilla — zero frameworks, consistent with this repo's philosophy)
- **API Layer:** Vercel Edge Functions for any backend data needs (consistent with this project's architecture)
- **Storage:** `localStorage` for session data; potential integration with a lightweight cloud store for persistent scripts

### Key Components

| Component | Description |
|---|---|
| Screenplay Editor | Scene-by-scene editor with act structure |
| Budget Planner | Line-item cost table with auto-summing totals |
| Character Registry | Character cards with roles, traits, and arc notes |
| Location Board | Location cards with map links and logistics notes |
| Reference Gallery | Image/video reference grid per scene (via API) |
| Sound Board | Audio reference links and mood tags |
| Cost Summary Dashboard | Visual breakdown of the full production budget |
